# Privacy Policy

Taskbar Monitor does not collect, store or send any personal data.

- Usage figures (CPU, GPU, VRAM, RAM) are read from Windows on your computer and shown on your screen only. They are never saved or sent anywhere.
- Your settings (which metrics to show, position, language) are stored in the Windows registry on your computer.
- The Microsoft Store version makes no network connections. The version downloaded from GitHub contacts the GitHub API (api.github.com) once a day to check for a newer release; GitHub may log that request as described in [GitHub's privacy statement](https://docs.github.com/site-policy/privacy-policies/github-general-privacy-statement).
- There are no analytics, ads or crash reporting.

Questions: open an issue at https://github.com/kieusonlam/taskbar-monitor/issues.
